# Movie App – React Native

A movie discovery mobile application built using React Native, Expo and TypeScript.

This project is currently under development. I'm building it step by step to improve my React Native development skills and explore mobile application architecture.

## 🛠️ Tech Stack

- React Native
- Expo
- TypeScript
- Expo Router
- NativeWind

##  Getting Started

Clone the repository:

```bash
git clone https://github.com/Aryanr99/React-Native-Projects.git
```

Install dependencies:

```bash
npm install
```

Start the Expo development server:

```bash
npx expo start
```
